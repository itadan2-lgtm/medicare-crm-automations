Field-Ready Setup

Setup Guide

Seven steps to get the compliance automations running on your own free accounts. No hosting, no subscriptions.

⏱ ~20 minutes 💵 $0 to run ↻ do once
Before you start
What you'll need
A Notion account with your duplicated CRM template
A free GitHub account
A free Vercel account (only for step 6)
This is a workflow aid, not legal advice. The SOA rule logic especially should get re-checked against current CMS guidance before you rely on it day to day.
New to this kind of setup? You don't need a coding background. Every command below has a Copy button, and each step says exactly what to click and where. Nothing here is permanent — the integration, the secrets, and the Vercel project can all be disconnected in a click if you back out.
Walkthrough
Seven steps
1
Duplicate the Notion template
If you haven't already, open the template and click Duplicate in the top right. Everything from here on refers to your copy — your IDs will be different from anything in this guide.
2
Create a Notion integration
Go to notion.so/my-integrations → New integration. Name it anything. Copy the secret it gives you — that's your NOTION_API_KEY.
notion.so/my-integrations
My integrations + New integration

Then, for each of the 7 databases (Clients, Leads, SOA Records, Appointments, Policies, Carrier Reference, Tasks), open it and connect your integration:

Repeat this for all 7 databases — Notion doesn't inherit the connection from the parent page.

3
Find your data source IDs
Open a terminal in the unzipped folder and run — tap any line below to copy it:
$ npm install
$ npm run find-ids -- <link to your Home page>
 
Paste this into your .env:
CLIENTS_DATA_SOURCE_ID=1aa33263-ad2f...
LEADS_DATA_SOURCE_ID=e3c3dcbe-76d3...
...
This exists because hunting these down by hand through the raw API is genuinely annoying. Don't do that.
4
Set your secrets
Copy .env.example to .env for local testing, or add each name straight to GitHub: repo → Settings → Secrets and variables → Actions.
github.com/you/medicare-crm-automations/settings/secrets/actions
NOTION_API_KEYUpdated 2m ago
CLIENTS_DATA_SOURCE_IDUpdated 2m ago
APPOINTMENTS_DATA_SOURCE_IDUpdated 2m ago
···

Email/SMS variables are optional — leave them blank and the scripts just log to console instead.

5
Turn on the daily checks
The included workflow runs automatically once secrets are set (8am ET by default). Trigger it by hand first to confirm it works before trusting it unattended:
github.com/you/medicare-crm-automations/actions
Daily Compliance & Deadline Checks
Run #14 · completed · 38s ago
Run #13 · completed · 1d ago
Run workflow ▾
6
Deploy the lead webhook optional
Only needed if you want form submissions to auto-create leads. Push this repo to your own GitHub, then:
vercel.com/new
Import Git Repository
you/medicare-crm-automations Import
Add the same Notion variables plus WEBHOOK_SECRET under Vercel's Environment Variables. Point Tally, Typeform, or a plain form at https://your-project.vercel.app/api/lead-webhook.
7
Test it
$ npm test
24 passed, 0 failed
7 passed, 0 failed
 
$ npm run soa-check
Checking 5 appointment(s)...
Done. 3 appointment(s) flagged.
The second command runs a real check against your actual Notion data — the fastest way to know everything's wired up right.
